✅ Feature Acceptance Criteria & Verification Matrix
6 Verified Capabilities

Verifiable acceptance criteria from prd.md > Features and Behavior to be tested directly during 5-build.

1. Cultural TasteMatch Engine
  • Inputting blended cultural prompts ranks items with affinity scores >= 90%.
  • Clicking preset cultural seed chips updates catalog items instantaneously.
  • Each card renders origin provenance tags and cultural rationale tooltips.
2. Conversational AI Sales Negotiator
  • Agent evaluates proposals against merchant margin floors before responding.
  • Adversarial prompts ("give it for $1") trigger polite deterministic price boundaries.
  • Agent suggests volume bundle incentives to preserve merchant transaction value.
3. Landed-Cost Markdown Cards
  • Agreed pricing outputs an itemized Markdown table directly inside chat stream.
  • Landed arithmetic strictly balances: (Base - Disc) + Customs + Shipping = Net.
  • Markdown card embeds an actionable 15-minute escrow locking button.
4. Multi-Day Milestone Escrow Ledger
  • Funds cannot transition to DISBURSED without confirmed DELIVERED status.
  • Simulating dispatch generates tracking airway bill (e.g. DHL-GLO-8921-X).
  • Dispute hold immediately halts automated release timers and freezes escrow.
5. Dual Payment Gateways
  • Single-click toggle between PayPal Sandbox and Internal Ledger Wallet.
  • Internal Wallet provides $500.00 pre-funded test balance for instant reviews.
  • Insufficient balance shows explicit top-up prompt rather than silent failure.
6. Seller Control Room & Margin Guard
  • Interactive sliders dynamically adjust floor margin % and max discount %.
  • In-memory invariant guard overrides any LLM response breaching profit floor.
  • Historical escrow disbursement ledger displays all settled merchant payouts.
🎯 Scope Boundary, Non-Goals & Architectural Decisions

✅ What We're Building (POC)

  • Cultural TasteMatch semantic affinity scoring engine
  • Autonomous conversational price negotiator with profit floor guards
  • Dynamic Markdown landed-cost table generator
  • 4-state milestone escrow state machine (LOCKED to DISBURSED)
  • Dual checkout gateway (PayPal Sandbox + Internal Ledger)
  • Seller control room drawer with interactive bounds

⏳ Deferred From POC (Future Road)

  • L2 blockchain USDC smart contract escrow on Solana/Base
  • Live official government customs API (HS tariff lookups)
  • Direct live courier hardware/satellite telematics integration
  • Shopify / WooCommerce live catalog inventory sync
  • Multi-party legal arbitration courtroom interface

Key Architectural Product Decisions & Tradeoffs

Decision Area Selected Approach Strategic Tradeoff & Rationale
Pricing Guard Deterministic Boundary Layer Constrains LLM counter-offers by hard mathematical code guards rather than trusting prompt-only safeguards. Eliminates hallucinated pricing exploits.
Landed Cost UI Inline Markdown Table Cards Embeds financial breakdown tables directly in chat feed instead of kicking user out to external cart screen. Keeps conversational bargaining context.
Escrow Release 4-Stage Milestone State Machine Releases funds progressively on verified delivery milestones rather than binary instant capture. Solves cross-border non-delivery anxiety.
Verification Dual-Mode (PayPal + Internal Wallet) Supports real PayPal Sandbox API calls while providing a pre-funded internal mock wallet so evaluators can test instantly without credential friction.
